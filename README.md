# Kawaii Chord Maker — Landing Page

公式サイト用のランディングページです。

## アプリについて

**Kawaii Chord Maker** は、歌詞にコードを乗せてコード譜をかんたんに作れるデスクトップアプリです。

### 主な機能

- 歌詞フレーズごとにコードを配置
- リアルタイムプレビューでコード譜を確認
- コードビルダー内蔵（ルート音＋コードタイプで選択）
- トランスポーズ（移調）機能
- ランダマイズ機能
- マイパレット（よく使うコードを保存）
- フォントサイズ・余白・行間・2カラム表示のレイアウト調整
- `.kcm` 形式でファイル保存
